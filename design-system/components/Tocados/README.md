# Tocados

La lista de archivos que tocó la última búsqueda, en la columna lateral, con cuántos fragmentos salieron de cada uno. Los que citó la respuesta se resaltan.

## Variantes

- `.tocado`: nombre en `mono` 14px `nieve`, conteo en `niebla` con números tabulares.
- `.tocado.citado`: el nombre pasa a `tinta` sobre una franja de `resaltador`, como si estuviera marcado con resaltador.

## Qué provee quien lo usa

Por archivo: el nombre (sin carpetas), la cantidad de fragmentos y si fue citado, con un `aria-label` completo. Cerrá la lista con `.tocados-nota` explicando el resaltado.
