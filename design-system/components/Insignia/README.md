# Insignia

Etiqueta de una o pocas palabras en la cabecera de un fragmento: si la respuesta lo citó y si llegó con la búsqueda híbrida.

## Variantes

- `.insignia`: borde `regla-fuerte`, texto `grafito`, 14px 700, `radio-pill`. Es la base ("No citado").
- `.insignia-citado`: `resaltador` con borde y texto `tinta`.
- `.insignia-nueva`: borde y texto `hibrida`.

## Qué provee quien la usa

Un `<span class="insignia …">` con el texto dentro de `.insignias` (gap `espacio-6`).
