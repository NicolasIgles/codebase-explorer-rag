# Sugerencia

Preguntas de ejemplo en la bienvenida, en una grilla de dos columnas (una en pantallas chicas). Cada una dice de qué tipo es y la pregunta completa.

## Variantes

- `.sugerencia`: `hoja`, borde `regla` que pasa a `tinta` al hover, `radio-14`, mínimo 72px. Tipo en `detalle` `grafito`, pregunta en 700.
- `.sugerencia-sin`: fondo transparente y borde punteado `regla-fuerte`, para una pregunta que el proyecto no puede responder: muestra la abstención.

## Qué provee quien lo usa

El tipo (Código, Documentación, Código y documento, Documento, o "No está en el proyecto") y la pregunta, con signos de apertura.
