# MensajeUsuario

La pregunta de la persona en el hilo: burbuja `tinta` con texto blanco, alineada a la derecha, `radio-20` con la esquina inferior derecha en 6px.

## Qué provee quien lo usa

Un `<p class="msg-usuario">` dentro de un contenedor grid (`.turno`), con el texto tal como se escribió: respeta saltos de línea y corta palabras largas. Ancho máximo `min(78%, 36em)`, `mensaje` (17px).

## Evitá

- Ponerle avatar o nombre: el hilo es de una sola persona.
